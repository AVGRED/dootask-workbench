# 任务模板的创建与使用

## 是什么
任务模板（ProjectTaskTemplate）把常用的任务标题、描述和子任务清单保存下来，下次新建任务时套用。每个模板属于一个项目；读取项目模板需要是该项目成员。跨项目使用时，用户需要同时属于模板来源项目和目标项目，并且目标项目开启模板共享。

## 入口
- 桌面端：项目详情页「+ 添加任务」对话框 → 顶部「模板」下拉
- 桌面端：项目设置 → 「任务模板」可统一管理（增删改默认模板）

## 创建模板
1. 进入项目设置 → 任务模板 → 「+ 新增模板」
2. 填模板名（用于下拉显示）、任务标题和富文本内容；可设置主任务预估工时（分钟），并为主任务和子任务选择项目里程碑；最多配置50个子任务节点，支持5层嵌套；每项可设置负责人策略和相对父任务开始日期的偏移
3. 可选标记 `is_default` 让它作为新建任务的默认套用项

## 使用模板
1. 在新建任务对话框顶部选择模板；跨项目搜索时可以先预览标题、内容、里程碑和子任务
2. 确认套用后，标题、描述、预估工时、里程碑与子任务计划会填入表单；可在新建任务表单中调整预估工时，子任务区会自动展开；取消勾选的子任务不会创建
3. 子任务负责人可设为当前用户或跟随父任务负责人；相对日期以父任务开始日期为基准，留空时沿用父任务计划时间
4. 每次使用会自增模板的 `use_count` 与 `last_used_at`

模板管理和跨项目预览会显示模板版本号与更新时间；模板内容有实际变化时版本号递增。创建任务时会提交套用时读取到的模板版本；若模板在表单打开期间被更新，系统会提示重新选择，避免把旧内容记录成新版本。由模板创建的主任务会记录模板名称和版本，可在任务详情顶部查看；已创建任务保存自己的标题、内容和子任务，后续编辑模板不会回写已有任务。

模板的里程碑按名称保存。跨项目套用时会在目标项目匹配同名里程碑；如果目标项目缺少对应里程碑，本次任务创建会提示错误，需先在目标项目创建里程碑或调整模板。

在项目设置的任务模板卡片中打开「历史版本」，可查看当前版本以及之前保存的名称、标题、内容、预估工时、里程碑和子任务，并查看历史记录中的修改人。模板卡片保留最初创建者；项目负责人可以恢复历史版本，恢复不会覆盖旧版本，而是保存当前内容并创建一个新的版本号。

## 不支持
- 模板不携带附件、主任务负责人或主任务计划时间
- 模板树最多支持5层、50个子任务节点
- 模板默认按项目隔离；开启目标项目的 `task_template_share` 后，当前用户加入的其他项目模板也可用于该项目
