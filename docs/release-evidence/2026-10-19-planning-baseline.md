# 2026-10-19 规划功能性能基线（冒烟）

本记录给出项目规划相关查询的**本地冒烟基线**，用于发现算法级回归（N+1、意外的全表扫描），不代表生产性能；生产基线仍需按[发布验收清单](../release-acceptance-checklist.md)第 7 节在接近生产的硬件与数据量上测量。

## 环境与方法

- WSL Ubuntu 22.04，PHP 8.4.26，MariaDB 10.6（隔离临时实例），临时 Redis
- 数据：1 个项目、200 个主任务（每个 1 天计划区间）、199 条 FS 依赖组成单链；直接插入依赖行以避免播种开销
- 测量：`DB::listen` 统计查询数，`microtime` 统计耗时；每个查询单独测量
- 复现：

```bash
DOOTASK_PERF_SMOKE=1 bash scripts/release-run-unit-tests-isolated.sh Feature --filter PlanningPerformanceSmokeTest
```

## 结果（2026-10-19，单次运行）

| 查询 | 耗时 | 查询数 | 说明 |
|---|---|---|---|
| 种子数据 | 0.29 s | — | 200 任务 + 199 依赖 |
| 排期预演 `preview`（锚点后移 1 天） | **0.106 s** | **94** | 级联 86 个任务（节假日/周末跳过） |
| 容量汇总 `capacity`（30 天） | 0.012 s | 9 | 200 任务的估时/实际聚合 |
| 依赖风险 `riskSummary` | 0.041 s | 7 | 199 条边分块扫描 |
| 甘特依赖 `projectLists`（200 个任务 ID） | 0.055 s | 7 | 返回 199 条边 |

## 结论

- 预演查询数随任务数近似线性（约 0.5 条/任务），未出现按任务逐个查询的 N+1；
- 容量汇总、风险汇总、甘特依赖查询均为常数级查询数，耗时在 60 ms 以内；
- 冒烟测试内置宽松阈值（预演 < 10 s / < 2000 查询，其余 < 5 s / < 500 查询），仅用于拦截数量级退化。

## 范围限制

- 单实例、无线程/连接并发，未验证锁竞争与死锁重试路径的耗时；
- 数据集 200 任务，低于预演上限 2000 任务；上限规模需在阶段 2 用生产副本测量；
- 隔离库与临时目录、无真实磁盘 IO 压力，不能作为容量规划依据。
